# Technopreneurship Educational Tour — Solicitation Landing Page

A complete, responsive, and high-fidelity solicitation landing page built for **Antonio Jr. S. Del Rosario**, a 3rd-year BSIT student at the University of Mindanao, raising **₱30,000** for the **4-Day, 3-Night Technopreneurship Educational Tour to Manila, Philippines**.

Designed faithfully based on the official design specification in **`Assets/SolicitationPageMainDesign.pdf`** and styled with the color palette from **`Assets/colorPaletes.png`**.

---

## 🚀 Running the Project

You can run this project locally using any of the following commands:

### Option A: Using NPM (Recommended)
```bash
npm run dev
# or
npm start
```
*Runs a local server at `http://localhost:3000` via `serve`.*

### Option B: Using Python
```bash
python -m http.server 3000
```
Then navigate to **[http://localhost:3000](http://localhost:3000)** in any modern web browser.

## 🔤 Typography

- **Headings & Display**: **Poppins** (`font-family: 'Poppins', sans-serif`, weights: 600, 700, 800)
  - Natural vertical proportions, tall un-flattened letterforms, crisp letter-spacing.
- **Body & UI Elements**: **Montserrat** (`font-family: 'Montserrat', sans-serif`, weights: 400, 500, 600)
  - Balanced line-heights and high legibility across all screen sizes.

## ⚡ Direct Support & Features

1. **Direct QR Code Reveal**:
   - Both **GCash** and **Maya** QR codes are directly visible in the Support section with high-resolution frames, verified InstaPay badges, 1-click number copy buttons, and instant download buttons.
2. **Interactive Photo Gallery with Filter Tabs**:
   - Filter by *All Photos*, *GDG DevFest*, *American Corner*, *Avalanche & DeFi*, *IDEAS Davao*, *Team BIDA*, and *Industry & Clients*.
3. **High-Resolution Lightbox**:
   - Clicking any photo opens an edge-to-edge modal preview with contextual captions.
4. **1-Click Copy Alerts**:
   - Fast clipboard copy for phone numbers, Discord handle, and account details.
